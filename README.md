# Практическая работа №1.1 — Первая модель

## Цель работы

Создание консольного приложения на Node.js
с использованием Sequelize и SQLite.

## Предметная область

Автомобили. Таблица хранит марку, модель,
год выпуска, цену и доступность автомобиля.

## Структура проекта

- database.js — подключение к базе данных.
- models/Car.js — описание модели автомобиля.
- index.js — создание таблицы, добавление записей,
  выборка и вывод данных.
- .gitignore — исключение служебных файлов.

## Используемые технологии

- Node.js
- Sequelize
- SQLite
- sqlite3

## Запуск

Установить зависимости:

npm install

Запустить приложение:

npm start

## Результат

Приложение создаёт таблицу автомобилей,
добавляет две записи при первом запуске,
получает все записи и выводит их в консоль.
